# v0.10.0 — seek previews and safer media controls

Marquee adds scene-thumbnail seek previews and confirmed media deletion, alongside improvements to Bazarr setup and dialogue enhancement.

## What's new

- **Seek preview.** The first Left or Right press opens a scene-thumbnail preview; OK seeks and Back cancels. Instant D-pad seeking remains optional.
- **Delete from the hold-menu.** Movies, episodes and whole shows can be deleted after confirmation. Plex Watchlist cleanup reports partial failures.
- **A refreshed look.** A Rosé Pine folded-M icon and splash accompany consistent package-controlled display names across the app and launcher.
- **Project information.** About, support and privacy notices use fork links and updated data disclosures.

## Fixed

- **Bazarr setup.** The native keyboard's literal address and key text are accepted, invalid drafts are retained, and typed text is excluded from diagnostics.
- **Dialogue enhancement.** Unusable audio decisions are rejected and the previous playback route is restored if the replacement fails.

## Known issues

- **Audio reload.** On a single playback engine, reloading audio may briefly interrupt playback.
- **Watchlist cleanup.** Some older Plex metadata cannot be matched safely; the app reports unconfirmed cleanup rather than removing the wrong entry.
- **Seek thumbnails.** A title without a Plex scene index has no thumbnail.
- **Device coverage.** Startup, Settings, native address typing and the Bazarr connection were checked on the TV. Extended playback and actual media deletion have not been tested.

## Installing

The stable package is named **com.beb.plxnative_0.10.0_arm.ipk** and can be installed with the [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) or [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). The package hash is filled from the artifact when available:

```
__IPK_SHA256__  com.beb.plxnative_0.10.0_arm.ipk
```
