# v0.12.0 — Browse all Discover matches

Discover keeps a short row of popular matches and opens the full movie results in a separate grid.

## What's new

- **Narrow down a movie search.** Pick a decade or a custom year range, combine themes or search for one by name, and filter by original language and runtime.
- **Browse beyond the first row.** All matches shows the result count and opens a grid with pages. Sort by popularity, rating or release date. Back returns to Discover with the filters in place.
- **Read the full plot.** Requests title pages show the synopsis once, in About. Long plots can be read with the remote without leaving the title page.

## Compatibility

Discover filters movies from a configured Seerr server. See the [Marquee release audit](https://github.com/nphil/Marquee/blob/main/docs/release-audits/v0.12.0.md) for test coverage. The package does not send crash or usage reports.

## Installing

Download **com.beb.plxnative_0.12.0_arm.ipk** from the [Marquee release](https://github.com/nphil/Marquee/releases/tag/v0.12.0) and install it with [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). The fork shares its install ID with PlxNative, so the two stable packages cannot be installed side by side.

```
__IPK_SHA256__  com.beb.plxnative_0.12.0_arm.ipk
```
