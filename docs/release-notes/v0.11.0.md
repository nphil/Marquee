# v0.11.0 — Discover movies and shows in Requests

Requests makes it easier to find a title that is not in Plex yet and follow what happens after it is requested.

## What's new

- **Browse by genre and release period.** Requests keeps the horizontal shelves and puts both filters within reach of the remote.
- **See what can be watched or requested.** Requests shows each title's availability before opening it; the title page shows what can be requested for that movie or series.
- **Follow requests.** My Requests distinguishes items awaiting approval, approved items, downloads, and titles that are available, when Seerr reports those states.

## Setting up Requests

Requests is optional. In Settings > Integrations > Requests, enter the address of a Seerr server and turn on Requests. An existing address stays in place. Catalogue data and artwork come from [The Movie Database](https://www.themoviedb.org/) through the Requests integration.

This application uses TMDB and the TMDB APIs but is not endorsed, certified, or otherwise approved by TMDB.

## Compatibility

See the [Marquee release audit](https://github.com/nphil/Marquee/blob/main/docs/release-audits/v0.11.0.md) for what was tested. The package does not send crash or usage reports.

## Installing

Download **com.beb.plxnative_0.11.0_arm.ipk** from the [Marquee release](https://github.com/nphil/Marquee/releases/tag/v0.11.0) and install it with [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). The fork shares its install ID with PlxNative, so the two stable packages cannot be installed side by side.

```
__IPK_SHA256__  com.beb.plxnative_0.11.0_arm.ipk
```
