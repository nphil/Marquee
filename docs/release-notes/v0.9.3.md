# v0.9.3 — subtitle settings with a live preview, and a way out when subtitles are wrong

This release adds a Settings > Subtitles page with a live preview, subtitle looks and presets, bundled subtitle fonts, "Reveal as spoken", a Wrong subtitles? flow that removes an external subtitle from Plex or finds another one with Bazarr, and a typed Bazarr entry in Settings.

## What's new

- **Settings > Subtitles.** Every part of the look is a row: preset, font, size, colour, opacity, bold, edge and its width, background box with colour, opacity, corner radius and padding, position and distance from the edge, line spacing, Blend with video, Reveal as spoken and how a file's own styling is treated. LEFT and RIGHT change a value. A live preview beside the list draws sample lines (accents, Japanese/Korean/Chinese, Arabic and Hebrew, symbols and emoji, italics, a styled file) over a bright, dark or snowy scene with the player's own renderer.
- **Settings > Integrations > Bazarr.** Type the address and API key on the television's keyboard, test the connection (Connected, Can't reach, key refused, not Bazarr) or forget them. The key is shown as dots and never printed.
- **File styling.** A subtitle file that brings its own fonts, colours and sizes can be drawn in the viewer's look instead (Settings > Subtitles > File styling > My look); signs and positioned lines keep the file's own look.
- **Subtitle looks.** The player's Subtitles > Style pages gain Preset, Font, Edge, Background, Reveal and Blend with video, saved per profile. Presets: Blend with video (recommended), Apple TV, Classic, Netflix, Outline, Large print, High contrast and Marquee.
- **Blend with video.** Soft, slightly translucent text with a diffuse shadow that follows the scene's brightness and stays below HDR peak.
- **Reveal as spoken.** Off, word by word or line by line, timed from each cue.
- **Fonts.** Noto Serif, Noto Sans Mono and Atkinson Hyperlegible join Inter, with an emoji fallback, so a symbol or emoji in a subtitle no longer draws as an empty box.
- **Wrong subtitles?** In the Subtitles menu: remove an external subtitle from Plex (an embedded track says it cannot be removed), or find another with Bazarr, with its score, language, provider and hearing-impaired flag. The pick is downloaded, Plex refreshes the item and the new track is selected.
- **Bazarr link.** The address and API key are stored in the protected session record like the Plex tokens. `tools/import-bazarr-link.sh` can still load them once from a key file.

## Known issues

- **Karaoke colours.** With File styling set to My look, a karaoke line is drawn in the viewer's single colour; its timing is kept.
- **Not watched on a television.** This build was made on a host with no television; none of the above has been seen on a set.

## Installing

Download **com.beb.plxnative_0.9.3_arm.ipk** and install it with the [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) or [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  com.beb.plxnative_0.9.3_arm.ipk
```
