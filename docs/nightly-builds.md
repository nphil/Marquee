# Nightly builds

Marquee does not currently advertise a Homebrew Channel nightly repository. The repository at `plxnative.com/nightly/` belongs to upstream PlxNative and does not distribute this fork.

Check [Marquee releases](https://github.com/nphil/Marquee/releases) for available builds. Install an available `.ipk` with webOS Dev Manager and verify its checksum as described in the [installation guide](install-and-verify.md).

A locally built nightly uses the separate app ID `com.beb.plxnative.nightly`, with its own sign-in and settings. It does not replace the stable install.
