# Release audit — v0.10.0

The evidence behind [the v0.10.0 release note](../release-notes/v0.10.0.md).

## Device test evidence

On 2026-10-31, the stable update was installed on the LG o22n2 platform running webOS 10.2.1. Profiles, Home and Settings opened with the stored account, remote navigation worked, and a character entered through the native keyboard appeared in the Bazarr address draft. The first Back dismissed the OS keyboard; the next cancelled the draft and restored the saved address. Bazarr Test connection reported Connected with the key masked, and Instant D-pad seeking was Off for the active profile. This establishes native UI and connection behaviour, not playback compatibility.

The focused regression run passed 93 checks across seven crate binaries. ARM ELF and package checks passed, and deployment compared all 54 payload files successfully. These checks do not establish television playback or deletion behaviour.
