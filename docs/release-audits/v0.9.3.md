# Release audit — v0.9.3

The evidence behind [the v0.9.3 release note](../release-notes/v0.9.3.md).

## Device test evidence

None for this release. It was built and checked on a host with no television access; it has not been
installed or run on a set. The host unit suites for `plx_plex`, `plx_data`, `plx_media`, `plx_appkit` and
`plx_screens` ran. In `plx_plex` and `plx_media` the failures that remain are the ones that need a
read-only directory to refuse a write, which a root-owned container does not give.

## Known issues at release, with provenance

- The Settings > Subtitles preview draws its pictures as plain gradients, not a film frame, and its
  libass frame is scaled down from the 1920 by 1080 canvas.
- With File styling set to My look, libass replaces a file's fonts, sizes, colours and edges on every event
  that is not explicitly placed; a karaoke line loses its two colours and keeps its timing.
- The typed Bazarr entry uses the television's own keyboard, which the desktop simulator does not have.

## Deliberately not done

Exact word timing for Reveal as spoken: it is estimated from each cue's timing. Aligning to the audio needs
a server-side step (for example WhisperX on a GPU) and is not built. Sonarr and Radarr ("get another
version of this file") are left as an extension point.
